## 📖 ما هو Voice Server؟

**Voice Server** هو خادم اتصالات متكامل يُبنى بمعمارية **Hexagonal (Ports & Adapters)** — بحيث يمكن استبدال أي مكون (تخزين، وسائط، ذكاء اصطناعي) دون إعادة كتابة منطق الأعمال.

يبدأ كـ **سيرفر مغلق بتأمين مدير واحد**، ويستطيع التطور إلى **منصة اتصالات كاملة** تخدم آلاف المستخدمين — عبر إضافة ملفات جديدة، لا تعديل الموجود.

> **الوعد:** انتقال أي مرحلة إلى التالية = ملفات جديدة فقط. إذا احتجت تعديل ملف موجود لتنمو = المعمارية مكسورة.
